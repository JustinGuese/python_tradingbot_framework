# Walk-forward re-tune on alpha vs QQQ — 2026-09-21

Every live, backtestable bot with a `param_grid` was re-tuned on the new
objective, `alpha_t` (the t-stat of alpha vs QQQ; see CLAUDE.md).

**No bot's parameters changed.** No grid winner beat the current defaults out of
sample by more than noise.

## Method

`scripts/onetime_retune_walkforward.py`:

1. **Data:** yfinance daily bars, 2019-01 → 2026-09, run through each bot's own
   `getYFDataWithTA`. Bot overrides that enrich the data therefore behave as
   they do live. The harness runs offline: bot rows go to a scratch SQLite file,
   and nothing touches Postgres.
2. **Search (H1 = 2019–2022):** grid-search by `alpha_t`, sampling up to the
   listed number of combos.
3. **Judge (H2 = 2023–2026, unseen):** score the H1 winner and the current
   defaults. New parameters ship only if they beat the defaults on H2, have
   positive H2 alpha, and the margin is larger than noise.

Costs: default slippage of 5 bps and the no-trade band. Cash earns 0% here; live,
the copier parks it in SHV.

## What this says

- **In-sample winners mostly fall apart.** SwingTitanium goes from +21% to +0.2%,
  and AdaptiveMeanReversionBTC from t 2.08 to 1.15. This is exactly why tuning on
  the full sample, as the old `local_development` workflow did, cannot be trusted.
- **TARegimeMultiAssetBot is the only bot with the same alpha in both halves:**
  +3.1% each, beta 0.11, full-sample t 1.72. It is the most credible alpha
  sleeve in the fleet, and it is still paper-only.
- **TARegimeAdaptiveBot (SPY) is negative out of sample** under both parameter
  sets. Its +14% live alpha should be read as luck.
- **AdaptiveMeanReversionBTCBot** reaches t 2.11 over the full sample, but only
  because it holds BTC, which QQQ does not explain. The drawdown is 75%. That is
  BTC's own risk premium, not timing skill.
- **GptBasedStrategyBTCTabased** needs six simultaneous conditions to enter
  (golden cross, ADX, RSI, MACD histogram, price above the fast SMA, and a
  Bollinger %B below 0.5). Also, the SMAs its comments call "50/200-day" are the
  TA library's 12/26-period `trend_sma_fast/slow`. On BTC daily bars the rule
  essentially never enters, so it is not an alpha source at any parameter setting.
